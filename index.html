Raíces de polinomios

Una raíz es el valor de x que hace que el polinomio valga cero: P(r) = 0.

Teorema del Factor(x − r) es factor de P(x) si y solo si P(r) = 0.
Teorema Fundamental del ÁlgebraUn polinomio de grado n tiene n raíces, contando multiplicidades.
MultiplicidadEn (x − 3)², la raíz 3 aparece dos veces.

Gráfica

Elige un polinomio. Las raíces están donde la curva toca el eje x. Pasa el dedo o el cursor por la gráfica para ver P(x).

División sintética paso a paso

Se multiplica por r y se suma, columna por columna. Si el último número es 0, r es raíz.

Ejercicio práctico

Hallar todas las raíces de P(x) = x³ − 6x² + 11x − 6. Selecciónalo arriba y prueba r = 1, 2, 3 y 4 en la división sintética.

Ver solución

1. Candidatos: ±1, ±2, ±3, ±6.
2. P(1) = 0, así que x = 1 es raíz.
3. División sintética entre (x − 1) da x² − 5x + 6.
4. x² − 5x + 6 = (x − 2)(x − 3).

Raíces: x = 1, 2 y 3. Vieta: suma = 6 y producto = 6 ✓

Plus para software

La división sintética es la Regla de Horner: un ciclo que repite «multiplicar y sumar». Evalúa un polinomio con n multiplicaciones en vez de n(n + 1)/2.

def division_sintetica(coef, r):
    res = [coef[0]]
    for c in coef[1:]:
        res.append(c + res[-1] * r)
    residuo = res.pop()
    return res, residuo

print(division_sintetica([1, -6, 11, -6], 1))  # ([1, -5, 6], 0)

En código, una raíz se verifica con tolerancia: abs(P(r)) < 1e-9, no con == 0.
